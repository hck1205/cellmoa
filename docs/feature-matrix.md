# cellmoa 기능 매트릭스 (Handsontable+HyperFormula vs VisiGrid vs cellmoa)

> 목표: **두 레퍼런스가 각각 강한 영역을 전부 🟢으로 흡수한다.**
> Handsontable 진영의 유일한 우위는 *웹 그리드 UI*와 *검증된 함수 커버리지*,
> VisiGrid 진영의 우위는 *엔진 통합 I/O · 툴체인(CLI/diff/verify/replay) · AI 연동 · 제품 형태*다.
> 즉 cellmoa = **VisiGrid의 엔진·툴체인 + Handsontable급 웹 UI**.

## 범례

| 기호 | 의미 |
|:--:|---|
| 🟢 | 자체 기능으로 완비 |
| 🟡 | 부분 지원 / 외부 라이브러리·직접 구축 필요 |
| 🔴 | 없음 |

`cellmoa` 열은 현재 상태가 아니라 **목표치(전부 🟢)** 이며, `수용 기준`은 그 🟢을 "완벽하게 소화했다"고 판정할 수 있는 검증 가능한 조건이다.

## A. 그리드 UI

| # | 기능 | HoT+HF | VisiGrid | cellmoa | 수용 기준 |
|:--:|---|:--:|:--:|:--:|---|
| A1 | Web Grid UI | 🟢 매우 강함 | 🟡 | 🟢 | 100만 행 가상 스크롤 60fps, 셀 편집/선택/범위 드래그, 고정 행·열, 병합 셀, 정렬·필터, 컨텍스트 메뉴, 키보드 내비게이션(Excel 호환), 복사/붙여넣기(TSV·HTML) |

**갭:** 이 한 줄이 Handsontable 진영에서 가져와야 할 사실상 유일한 항목이지만, 난이도·분량은 나머지 전부와 맞먹는다. 라이선스 문제로 Handsontable 코드 차용은 불가 → 자체 렌더러 필요.

## B. 계산 엔진

| # | 기능 | HoT+HF | VisiGrid | cellmoa | 수용 기준 |
|:--:|---|:--:|:--:|:--:|---|
| B1 | Formula 계산 | 🟢 400+ 함수 | 🟢 | 🟢 | **함수 커버리지가 승부처.** HyperFormula 400+ 함수 목록을 기준선으로 삼고, 각 함수마다 Excel 실측값 대조 테스트를 둔다 |
| B2 | Dependency graph | 🟢 | 🟢 | 🟢 | 증분 재계산(변경 셀의 하위 그래프만), 순환 참조 검출·보고, 대량 편집 시 배치 재계산 |
| B3 | Node/headless 계산 | 🟢 | 🟢 | 🟢 | UI 의존 없이 순수 계산 코어만 임포트 가능, 동일 입력 → 동일 출력(결정적) |

**갭:** 세 항목 모두 양쪽이 🟢이므로 "따라잡기"가 아니라 **두 레퍼런스 수준을 동시에 만족**시키는 문제. 특히 B1의 400+ 함수는 물량전이라 초기부터 함수 카탈로그를 데이터로 관리해야 한다.

## C. 파일 I/O

| # | 기능 | HoT+HF | VisiGrid | cellmoa | 수용 기준 |
|:--:|---|:--:|:--:|:--:|---|
| C1 | XLSX import/export | 🟡 별도 라이브러리 필요 | 🟢 엔진에 통합 | 🟢 | 외부 의존 없이 엔진 내장. 수식·서식·시트 구조·명명범위 라운드트립 무손실(원본 → import → export → 재import 시 동등) |

**갭:** Handsontable은 SheetJS 등 외부 라이브러리 조합이 필요 → 수식 보존이 깨지기 쉬움. cellmoa는 파서를 엔진 내부에 둬서 수식 AST를 그대로 태운다.

## D. 무결성 · 검증 (VisiGrid 독점 영역)

| # | 기능 | HoT+HF | VisiGrid | cellmoa | 수용 기준 |
|:--:|---|:--:|:--:|:--:|---|
| D1 | Spreadsheet diff | 🔴 | 🟢 | 🟢 | 두 파일의 셀 값·수식·서식·구조 변경을 의미 단위로 출력, 행/열 삽입 이동 추적, 기계 판독 포맷(JSON) + 사람용 출력 |
| D2 | Spreadsheet fingerprint | 🔴 | 🟢 | 🟢 | 내용 기반 안정 해시 — 의미 없는 차이(저장 시각·zip 순서)에는 불변, 값·수식 변경에는 민감 |
| D3 | 결과 verify | 🔴 | 🟢 | 🟢 | 기대값 스펙 대비 계산 결과 검증, 실패 시 셀 좌표·기대·실제 리포트, 종료 코드로 CI 연동 |
| D4 | Replay | 🔴 | 🟢 | 🟢 | 기록된 편집 연산 로그를 재실행해 동일 최종 상태 재현(결정적) |
| D5 | Provenance / Audit | 🔴 | 🟢 | 🟢 | 셀 단위 변경 이력 — 누가(사람/에이전트) 언제 무엇을 왜 바꿨는지 추적, 조회 API 제공 |

**갭:** Handsontable 진영에 대응물이 아예 없는 블록. D2·D4는 **엔진의 결정성**에 의존하므로 B3(headless 결정적 계산)가 선행 조건이다. D5는 데이터 모델 설계 단계에서 들어가야지 나중에 붙일 수 없다.

## E. 자동화 · 확장

| # | 기능 | HoT+HF | VisiGrid | cellmoa | 수용 기준 |
|:--:|---|:--:|:--:|:--:|---|
| E1 | CLI | 🔴 핵심 제품 없음 | 🟢 | 🟢 | open/calc/diff/verify/export/fingerprint/replay 전부 CLI로 노출, 파이프 친화적 stdout, 비정상 시 비0 종료 코드 |
| E2 | CI/CD에서 실행 | 🟡 직접 구축 | 🟢 CLI 기반 | 🟢 | E1 위에서 성립. 헤드리스 환경에서 브라우저 없이 동작, 예제 GitHub Action 제공 |
| E3 | 내장 scripting | 🔴 | 🟢 Lua | 🟢 | 샌드박스 스크립트로 셀 읽기/쓰기/계산 트리거, 무한루프·파일접근 차단, 스크립트 변경도 D5 provenance에 기록 |

**갭:** E2는 E1의 파생이라 별도 기능이 아니다(원본 표에서 "직접 구축"이라 적힌 이유). E3의 언어 선택은 미결 — Lua를 그대로 갈지, JS 샌드박스로 갈지 결정 필요.

## F. AI 연동 (VisiGrid 독점 영역)

| # | 기능 | HoT+HF | VisiGrid | cellmoa | 수용 기준 |
|:--:|---|:--:|:--:|:--:|---|
| F1 | Local MCP | 🟡 HyperFormula는 예정 | 🟢 현재 제공 | 🟢 | MCP 서버로 시트 조회·편집·계산 툴 노출, stdio 전송 |
| F2 | Remote MCP | 🔴 | 🟢 | 🟢 | 원격 전송 + 인증, 세션별 문서 격리 |
| F3 | AI가 열린 스프레드시트 직접 조작 | 🔴 | 🟢 | 🟢 | 사용자가 UI에서 열어둔 문서에 에이전트 편집이 실시간 반영, 양방향 |
| F4 | 에이전트 변경 Undo/Redo | 🔴 | 🟢 | 🟢 | 에이전트가 만든 변경을 하나의 단위로 되돌리기 — 사람 편집 이력과 섞이지 않음 |
| F5 | 에이전트 동시 수정 보호 | 🔴 | 🟢 revision 기반 | 🟢 | revision 기반 낙관적 동시성 — stale revision 쓰기는 거부, 충돌을 호출자에게 반환 |

**갭:** F3~F5는 UI(A1)와 엔진이 **같은 문서 모델·revision을 공유**해야 성립한다. UI를 뷰어로만 만들면 나중에 못 붙인다 → 아키텍처 1일차 결정 사항.

## 정리: 원본 표에서 손본 것

1. **분류 추가** — 20개 행을 UI/엔진/IO/무결성/자동화/AI/제품 7개 축으로 묶었다. 축별로 선행 관계가 다르다.
2. **"CI/CD에서 실행" 행의 표기 정정** — Handsontable 쪽이 "직접 구축"으로 적혀 있었는데 이건 🟡이다. 그리고 이 행은 독립 기능이 아니라 CLI(E1)의 파생이다.
3. **수용 기준 열 추가** — "완벽하게 다 소화"를 판정하려면 행마다 합격선이 필요하다. 없으면 전부 자칭 🟢이 된다.
4. **선행 의존 명시** — D2/D4 ← B3, F3~F5 ← A1+공유 문서 모델, E2 ← E1. 순서를 틀리면 재작성이 발생하는 지점들이다.

## 물량 관점

- 🟢 **1개** 항목만 Handsontable에서 가져온다 (A1) — 단, 전체 공수의 절반에 육박.
- 🟢 **12개** 항목을 VisiGrid에서 가져온다 (D1~D5, E1·E3, F1~F5, G1~G2).
- 🟢 **4개** 항목은 양쪽 모두 이미 🟢이라 기준선이 높다 (B1~B3, C1).
