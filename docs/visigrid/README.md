# VisiGrid documentation, as received

docs.visigrid.app is blocked by this environment's network egress proxy, so
these pages were pasted in by hand rather than fetched. They are kept verbatim
because they are the specification the CLI is being built against, and because
a summary of a spec is not a spec.

Each file is one page. `status:` in the front matter says how far cellmoa has
absorbed it. Nothing here is a promise about what cellmoa will ship — a page
marked `not-applicable` names a VisiGrid product surface that has no cellmoa
counterpart (a hosted service, a desktop window), and says so rather than
being quietly dropped.
